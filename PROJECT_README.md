# Gowtham C K - Portfolio

Modern developer portfolio built with React, Vite, Tailwind CSS, and Framer Motion.

## 🚀 Getting Started

1. **Install Dependencies**

    ```bash
    npm install
    ```

2. **Start Development Server**

    ```bash
    npm run dev
    ```

3. **Build for Production**

    ```bash
    npm run build
    ```

## 🛠 Tech Stack

- **Framework:** React + Vite
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **Deployment:** GitHub Pages (ready)

## 📁 Project Structure

- `src/components`: UI components (Hero, About, Skills, etc.)
- `src/data.js`: Content data (easy to update)
- `legacy/`: Backup of the old site files

## 🚢 Deployment to GitHub Pages

1. Update `base` in `vite.config.js` if needed (e.g. `base: '/repo-name/'`).
2. Run `npm run build`.
3. Deploy the `dist` folder.
